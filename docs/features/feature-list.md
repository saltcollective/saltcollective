# Feature List

---

## Hub (Must)

- Business list - paginated listing of businesses in the hub (Must)
- Search businesses - search by name/type within the hub; scoped to the club's own businesses only (Must)
- Business card display (Must)
- Sponsor tier list (Must)
- Click tracking (Must)
- Hosted hub page (Must)
- Embeddable iframe (Should)

## Club Admin (Must)

- Hub setup / first-run (Must)
- Add a business (Must)
- Edit / remove a business (Must)
- Add / edit / delete sponsor levels (Could)
- Hub appearance customisation (Could)
- View analytics (Could)
- Billing / plan (Should)

## Onboarding (Must)

- Club sign-up (Must)
- Hub publish / go-live (Must)

## Site Admin (Must)

- Club management (Must)
- User management (Should)
- Billing (Could - depends on how much is surfaceable from Stripe and whether necessary)
- Analytics overview (Could)
- Impersonate user (Could)
